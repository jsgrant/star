## CT FOV 800 변환 (`fov_extend.py`)

CT 시리즈를 FOV 800 mm / 512 매트릭스(픽셀 1.5625 mm)로 넓혀 새 시리즈로 저장합니다.
CT 장비의 eFOV 800 시리즈와 같은 형식(영상 중심·좌표계 유지, 바깥은 공기 -1024 HU)입니다.

### 사용 (Windows)
1. `run_fov800.bat` 위에 환자 폴더(또는 imported 폴더)를 끌어다 놓거나, 더블클릭해서 폴더를 고릅니다.
   - 처음 한 번은 필요한 패키지를 이 폴더의 `.venv` 에 설치합니다 (Python 3.10+ 필요, 컴퓨터 전체에는 설치하지 않음).
2. 결과: `<고른 폴더>\FOV800 completed\<환자ID_이름>\S<번호>_<설명>_FOV800_<id>\CT_0001.dcm …`

명령줄: `python fov_extend.py <입력폴더> [출력폴더] [--fov 800] [--matrix 512] [--series-offset 100]`

### 안전장치
- CD/PACS 내보내기처럼 같은 영상이 두 곳(IHE_PDI, Storage)에 있어도 **한 번만** 변환 (SOPInstanceUID 기준)
- 시리즈마다 별도 폴더, 슬라이스는 z 순서로 저장, 새 시리즈 번호 = 원래 번호 + 100 (예: 2 → 102)
- 이미 FOV 가 목표 이상인 시리즈(앞서 만든 eFOV 결과 등), 스카우트(LOCALIZER), 멀티프레임은 건너뜀
- 결과 폴더 안의 파일은 다시 변환하지 않음. 다시 실행하면 같은 UID 로 덮어써서 중복이 생기지 않음

⚠ 장비의 raw data 재구성이 아니라서, 원래 FOV 밖으로 잘린 몸은 되살리지 못합니다 (형식만 맞춤).
검증된 의료기기가 아니므로 치료계획에 쓰기 전 반드시 확인하세요.

시험: `python -m pytest -q test_fov_extend.py`
